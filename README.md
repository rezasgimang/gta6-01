SOLMARA — an original open-world crime game in the spirit of GTA 6: a neon coastal city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level with police pursuit, three story missions as a courier for the Neon Tide crew, fist combat, a HUD with minimap, save and continue, and synth sound. Pure Canvas 2D, no assets, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
